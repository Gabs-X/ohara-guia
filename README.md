# Ohara Guia

Assistente de IA para Windows feita para quem **não é desenvolvedor**. Ela junta as suas assinaturas de IA (Claude, ChatGPT/Codex, Gemini) e uma IA grátis no seu PC, e escolhe sozinha a mais barata que resolve cada pedido.

## Baixar

Baixe a versão mais recente em **[Releases](https://github.com/Gabs-X/ohara-guia/releases/latest)**:

- `Ohara-Guia-Setup-<versão>.exe`: instalador (recomendado; se atualiza sozinho).
- `Ohara-Guia-Portatil-<versão>.exe`: roda direto, sem instalar.

O instalador não é assinado: se o Windows avisar, clique em **Mais informações** → **Executar assim mesmo**.

## Primeiro uso

Abra a Ohara Guia e siga a tela **Primeiros passos**: ela confere o que falta no PC (Node.js, Git e cada IA) e tem botões para instalar e fazer login. Basta **uma** IA pronta para começar.

## O que ela faz

- **Orquestração de IAs**: cada pedido vai para a IA com melhor custo-benefício no momento, repartindo a cota entre as assinaturas. Se uma falhar ou ficar sem cota, a próxima assume.
- **Planejador**: transforma uma ideia num plano em etapas e executa uma de cada vez.
- **Desfazer**: antes de mexer num projeto, a Ohara guarda um ponto de restauração.
- **Ferramentas locais**: perguntar aos seus documentos, extrair dados, triagem de mensagens, documento por foto e privacidade, tudo na IA local, sem o dado sair do PC.
- **Uso e economia**: quanto cada IA gastou e quanto a orquestração economizou.
